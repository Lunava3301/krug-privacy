# Krug — Privacy Policy

Политика конфиденциальности приложения «Круг» (Android), на английском и русском.

Страница: https://lunava3301.github.io/krug-privacy/

Текст собирается из строковых ресурсов приложения (`values/ui_strings.xml`,
`values-ru/ui_strings.xml`), поэтому страница и экран политики внутри приложения
совпадают дословно. Правки вносятся в приложении и переносятся сюда, а не наоборот.
